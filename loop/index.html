The checking loop

Two new meetings, and what changed because of them.

When something new arrives, the loop checks it against every page before anything is sent. One fact changes in one place, and every page follows. This is what happened between Friday 22 January and Friday 29 January 2027.

The method

Eight steps, in order

  1. Ingest the new input
  2. Extract facts, decisions and questions
  3. Check against every artefact
  4. List what changes
  5. Update the artefacts
  6. Update the changelog and actions
  7. Delete answered questions
  8. Run the checks

In short

What the loop is for

The loop makes sure a decision made in one meeting reaches every page that depends on it. It also keeps answered questions off the list, with the answer written on the page as fact. When the next transcript arrives, the same eight steps run again.
