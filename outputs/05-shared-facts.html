Shared facts

Draft v0.2 | 29 January 2027 | Change lead, Change Made Simple

Every date, name and number that appears on more than one page lives in one place. When a value changes, the change is made once and every page picks it up.

Changed in v0.2 Updated v0.2
  • The guardrails gate moves from Fri 26 Mar to Fri 9 Apr 2027 (T5, change C-3). It is the one edit shown on the third tab.
  • Wave 1 training and the school-holiday window carry the T5 decisions (change C-4).
  • Richard Vance is now Conditional, and three champions are added (T4, change C-1).

The facts file holds each value once, for example guardrails_gate, with a record of where it came from. Pages carry the token {{guardrails_gate}} in place of the date. The build replaces each token with the value and stops if a token is not defined. The check fails if a page still holds an old wording from the avoid list, so no page keeps an old date after it was fixed elsewhere.

Trap: Fri 26 Mar 2027 is still correct as Good Friday, so the avoid entry matches it only next to the words "guardrails" or "gate". A plain search for the date would flag the holiday and hide the real error.
